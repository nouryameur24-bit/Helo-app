[LOGIQUE MÉTIER EXIGÉE : L'ARCHITECTURE HYBRIDE]
Tu dois implémenter un système strict de "Cache Hit / Cache Miss" pour économiser les appels à l'API de Claude. Voici le flow exact que ton code doit respecter :

1. RECHERCHE SUPABASE : Chercher le produit via son `barcode` dans la table `products`.
- Si le produit n'existe pas du tout en base -> Renvoyer une erreur 404 "Produit introuvable".

2. CACHE HIT : 
Si `analysis_cache` contient déjà une analyse pour le `trimester` demandé, renvoyer immédiatement cette donnée au format JSON au frontend. Ne PAS appeler l'API Anthropic.

3. CACHE MISS (Le cœur de l'IA) :
Si l'analyse pour ce trimestre n'existe pas, tu dois appeler l'API Anthropic en lui envoyant la liste `ingredients_raw` et le nom du produit.

"Tu es un expert en toxicologie et en nutrition périnatale. Analyse la liste d'ingrédients de ce produit pour une femme au trimestre {trimester} de sa grossesse. 
Tu dois obligatoirement répondre UNIQUEMENT avec un objet JSON valide contenant ces clés :
- 'status': 'autorise', 'a_eviter', ou 'interdit'
- 'glow_score': un score sur 100
- 'explanation': une explication courte (2 phrases max) de ton verdict

4. MISE À JOUR DU CACHE :
Une fois la réponse JSON de Claude récupérée, mets à jour la colonne `analysis_cache` de ce produit dans Supabase (en ajoutant la clé correspondant au trimestre, sans écraser les autres trimestres potentiellement déjà en cache).
