Crée Hēlo Memories — capsules temporelles de grossesse pour le futur.

app/memories.tsx :

CONCEPT : à chaque fin de trimestre (ou manuellement), l'app compile automatiquement une "capsule" avec les moments forts. La capsule est scellée et ne s'ouvre qu'à une date future choisie par la maman.

CRÉATION DE CAPSULE :
- Déclenchée automatiquement à chaque changement de trimestre + option manuelle dans le profil
- L'app compile :
  * Glow Score moyen du trimestre
  * Nombre de produits scannés
  * Produit le plus scanné
  * Le scan le plus surprenant (premier produit danger trouvé)
  * Entrées journal du trimestre (si journal activé)
  * Messages du cercle (si cercle activé)
  * Semaines de grossesse couvertes
- L'utilisatrice peut ajouter :
  * Une photo de son ventre (expo-image-picker)
  * Un message vocal (expo-av recording, max 60s)
  * Un message texte pour son futur bébé (TextInput, placeholder "Cher(e) [prénom du bébé]...")

SCELLEMENT :
- "Quand souhaitez-vous ouvrir cette capsule ?" :
  * "À la naissance" (date = DPA)
  * "Au 1er anniversaire" (DPA + 1 an)
  * "Quand il/elle aura 5 ans"
  * "Quand il/elle aura 18 ans"
  * Date personnalisée
- Animation de scellement : la capsule (représentée par un cercle doré) se referme avec une animation de "fermeture à clé" (rotation + scale down + sparkles). Haptic Success.
- "Capsule scellée — rendez-vous le [date] 💛"

STOCKAGE :
- AsyncStorage "memory_capsules" : array de { id, trimester, data, sealedAt, opensAt, opened: boolean }
- La photo et l'audio sont sauvegardés dans le filesystem local (expo-file-system)
- Optionnel : backup sur Supabase Storage pour ne pas perdre les données

CAPSULES SCELLÉES (visibles dans le profil) :
- Liste des capsules avec :
  * "Trimestre 1 — scellée le [date]" 
  * Icône cadenas doré si pas encore ouverte
  * "S'ouvre le [date]" bodySmall textSecondary
  * Si la date est passée → icône cadenas ouvert + "Ouvrir votre capsule ✨" primary
- Au tap sur une capsule non ouverte → message "Cette capsule s'ouvrira le [date]. Patience 💛"
- Au tap sur une capsule ouvrable → animation d'ouverture (cadenas qui tourne, lumière dorée, particules) → affichage du contenu

CONTENU DE LA CAPSULE OUVERTE :
- Scroll vertical immersif, design éditorial premium
- Header : "Trimestre X — [dates]" displayMedium + photo ventre si uploadée
- Section "Votre grossesse en chiffres" : stats visuelles
- Section "Vos scans" : les plus marquants
- Section "Votre journal" : entrées du trimestre
- Section "Votre message" : le texte/audio pour le bébé (lecteur audio intégré)
- Section "Votre cercle disait..." : messages des amies
- Footer : "Avec amour, via Hēlo 💛"
- Bouton "Partager cette capsule" → PDF ou images partageables

NOTIFICATION : le jour où une capsule peut être ouverte → push notification spéciale : "Une capsule Hēlo vous attend ! Ouvrez-la pour revivre votre [trimestre] 💛"

PREMIUM : créer des capsules = gratuit (c'est du contenu qu'on ne veut pas bloquer). Ajouter photo/audio/message = premium.
