Configure Supabase comme backend pour l'app Hēlo. Installe @supabase/supabase-js.

Crée lib/supabase.ts : client Supabase avec variables d'env EXPO_PUBLIC_SUPABASE_URL et EXPO_PUBLIC_SUPABASE_ANON_KEY, persistence AsyncStorage.

Crée le schema SQL complet (supabase/schema.sql) :

TABLE profiles :
id (uuid PK FK auth.users), first_name (text), due_date (date), current_trimester (int 1-3), concerns (text[] ex: ['cosmetics','food','medication']), is_premium (boolean default false), partner_code (text unique 6 chars auto), linked_partner_id (uuid nullable FK profiles), disclaimer_accepted (boolean default false), created_at (timestamptz), updated_at (timestamptz)

TABLE ingredients :
id (uuid PK), name (text unique), name_inci (text nullable), synonyms (text[]), category (text: 'cosmetic'/'food'/'medication'), risk_level_t1 (text: 'safe'/'caution'/'danger'), risk_level_t2 (text), risk_level_t3 (text), risk_level_breastfeeding (text), description_fr (text), source (text), source_url (text nullable), created_at (timestamptz)

TABLE products :
id (uuid PK), barcode (text unique nullable), name (text), brand (text nullable), category (text), image_url (text nullable), ingredients_raw (text), ingredient_ids (uuid[]), source (text: 'openfoodfacts'/'community'/'manual'), verified (boolean default false), created_at (timestamptz)

TABLE scans :
id (uuid PK), user_id (uuid FK profiles), product_id (uuid FK products), trimester_at_scan (int), verdict (text: 'safe'/'caution'/'danger'), flagged_ingredients (jsonb), in_shelf (boolean default false), shelf_category (text nullable: 'bathroom'/'kitchen'/'pharmacy'), scanned_at (timestamptz default now())

TABLE community_submissions :
id (uuid PK), submitted_by (uuid FK profiles), barcode (text nullable), product_name (text), ingredients_photo_url (text nullable), ingredients_text (text nullable), status (text: 'pending'/'approved'/'rejected' default 'pending'), created_at (timestamptz)

Row Level Security :
- profiles: users read/update their own
- scans: users read/insert their own
- ingredients: all authenticated can read
- products: all authenticated can read
- community_submissions: insert own, read all where status='approved'

Crée lib/auth.ts : signUp(email, password, firstName, dueDate, concerns), signIn(email, password), signOut(), getCurrentUser(), updateProfile(updates)

Crée hooks/useAuth.ts : expose user, profile, loading, signUp, signIn, signOut

Mets les variables dans .env avec des placeholders.
