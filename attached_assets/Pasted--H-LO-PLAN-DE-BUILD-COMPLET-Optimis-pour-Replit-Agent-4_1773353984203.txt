# PROMPT 3 — Supabase Backend
# ⚡ PARALLEL GROUP A (avec Prompt 2)

```
Configure Supabase comme backend pour l'app Hēlo. Installe @supabase/supabase-js.

Crée lib/supabase.ts : client Supabase avec variables d'env EXPO_PUBLIC_SUPABASE_URL et EXPO_PUBLIC_SUPABASE_ANON_KEY, persistence AsyncStorage.

Crée le schema SQL complet (supabase/schema.sql) :

TABLE profiles :
id (uuid PK FK auth.users), first_name (text), due_date (date), current_trimester (int 1-3), concerns (text[] ex: ['cosmetics','food','medication']), is_premium (boolean default false), partner_code (text unique 6 chars auto), linked_partner_id (uuid nullable FK profiles), disclaimer_accepted (boolean default false), created_at (timestamptz), updated_at (timestamptz)

TABLE ingredients :
id (uuid PK), name (text unique), name_inci (text nullable), synonyms (text[]), category (text: 'cosmetic'/'food'/'medication'), risk_level_t1 (text: 'safe'/'caution'/'danger'), risk_level_t2 (text), risk_level_t3 (text), risk_level_breastfeeding (text), description_fr (text), source (text), source_url (text nullable), created_at (timestamptz)

TABLE products :
id (uuid PK), barcode (text unique nullable), name (text), brand (text nullable), category (text), image_url (text nullable), ingredients_raw (text), ingredient_ids (uuid[]), source (text: 'openfoodfacts'/'community'/'manual'), verified (boolean default false), created_at (timestamptz)

TABLE scans :
id (uuid PK), user_id (uuid FK profiles), product_id (uuid FK products), trimester_at_scan (int), verdict (text: 'safe'/'caution'/'danger'), flagged_ingredients (jsonb), in_shelf (boolean default false), shelf_category (text nullable: 'bathroom'/'kitchen'/'pharmacy'), scanned_at (timestamptz default now())

TABLE community_submissions :
id (uuid PK), submitted_by (uuid FK profiles), barcode (text nullable), product_name (text), ingredients_photo_url (text nullable), ingredients_text (text nullable), status (text: 'pending'/'approved'/'rejected' default 'pending'), created_at (timestamptz)

Row Level Security :
- profiles: users read/update their own
- scans: users read/insert their own
- ingredients: all authenticated can read
- products: all authenticated can read
- community_submissions: insert own, read all where status='approved'

Crée lib/auth.ts : signUp(email, password, firstName, dueDate, concerns), signIn(email, password), signOut(), getCurrentUser(), updateProfile(updates)

Crée hooks/useAuth.ts : expose user, profile, loading, signUp, signIn, signOut

Mets les variables dans .env avec des placeholders.
```

# PROMPT 5 — Open Food Facts
# ⚡ PARALLEL GROUP B (avec Prompt 4)

```
Intègre l'API Open Food Facts dans l'app Hēlo pour rechercher les produits alimentaires par code-barres.

Crée lib/openfoodfacts.ts :

1. fetchProductByBarcode(barcode: string): Promise<ProductData | null>
   - GET https://world.openfoodfacts.org/api/v2/product/{barcode}.json
   - Extraire : product_name, brands, image_url, ingredients_text_fr (ou ingredients_text)
   - Gestion d'erreurs : 404 (produit non trouvé), timeout 10s, erreur réseau
   - Type retour : { name, brand, imageUrl, ingredientsRaw, ingredientsList }

2. parseIngredients(ingredientsText: string): string[]
   - Parser le format OFF : virgules, parenthèses (sous-ingrédients), pourcentages
   - Normaliser : lowercase, trim, supprimer pourcentages, supprimer sous-éléments entre parenthèses
   - Retourner tableau propre

3. matchIngredients(ingredientsList: string[], trimester: number): Promise<MatchResult[]>
   - Pour chaque ingrédient, chercher dans Supabase "ingredients" par name ILIKE ou ANY(synonyms) ILIKE
   - Retourner : { ingredientName, matched: boolean, ingredient?: IngredientData, riskLevel?: string }
   - Non matchés : riskLevel = 'no_signal' (PAS "unknown" — formulation neutre)

4. getVerdict(matches: MatchResult[]): VerdictResult
   - Si au moins un 'danger' → verdict 'danger'
   - Si au moins un 'caution' sans danger → verdict 'caution'
   - Sinon → verdict 'safe'
   - Retourner : { verdict, flaggedIngredients (danger+caution), noSignalCount }

Crée hooks/useScan.ts :
- State : loading, product, verdict, error
- scanBarcode(barcode: string) : orchestre fetch OFF → parse → match → verdict
- Cache AsyncStorage par barcode (si déjà scanné, retourner en cache)

Crée un écran test temporaire app/test-scan.tsx avec un input pour taper un code-barres et voir le résultat. Utilise Card, Badge, Text du design system.
```

# PROMPT 23 — Offline Mode

```
Crée le mode offline de l'app Hēlo (feature premium).

lib/offline.ts :

1. downloadIngredientsDB(): Promise<void>
   - Fetch toute la table ingredients de Supabase
   - Stocker dans AsyncStorage key "ingredients_db" (JSON stringifié)
   - Stocker "ingredients_db_version" (timestamp)
   - Taille estimée : ~200 ingrédients × ~1KB = ~200KB

2. getLocalIngredients(): Ingredient[]
   - Lire depuis AsyncStorage, parser JSON

3. matchIngredientsLocal(ingredientsList: string[], trimester: number): MatchResult[]
   - Même logique que matchIngredients mais sur la base locale
   - Recherche par name.toLowerCase().includes() ou synonyms check

4. cacheProduct(barcode: string, product: Product, verdict: VerdictResult): void
   - Stocker dans AsyncStorage key "product_cache_{barcode}"
   - Max 500 produits (LRU : supprimer le plus ancien si > 500)

5. getCachedProduct(barcode: string): CachedScan | null

6. syncOfflineScans(): Promise<void>
   - Lire AsyncStorage "offline_scans" (array de scans faits hors ligne)
   - Pour chaque : insert dans Supabase scans
   - Vider le buffer local
```
