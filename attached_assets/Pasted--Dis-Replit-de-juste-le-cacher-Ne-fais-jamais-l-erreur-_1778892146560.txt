Voici la stratégie **Nature Peinture** pour gérer ça proprement sans perdre une seule ligne de ton travail :
### 1. Pourquoi "Masquer" est 100 % Safe pour l'App Store
Les testeurs d'Apple (et leurs outils de scan automatique) ne vont pas aller lire tes fichiers sources dans ton dossier app/ pour voir si du code dort. Ils se contentent de tester l'application compilée.
 * Si un écran n'a **aucun bouton** qui pointe vers lui, **aucune icône**, et qu'il n'est pas accessible dans la barre des onglets (Tabs), pour Apple, il n'existe pas. Tu passes le contrôle technique sans problème.
### 2. Comment le cacher proprement ?
Dans ton _layout.tsx, la route community est déjà configurée avec href: null (donc invisible dans la barre du bas). Mais le vrai piège, ce sont les boutons "raccourcis" cachés dans tes autres écrans.
Par exemple, dans ton fichier community.tsx, tu as le composant CircleCard qui redirige vers /circle. Si tu as d'autres liaisons sur ton écran d'accueil, c'est là que ça peut coincer.
