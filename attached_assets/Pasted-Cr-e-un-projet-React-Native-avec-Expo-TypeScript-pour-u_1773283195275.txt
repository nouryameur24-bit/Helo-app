Crée un projet React Native avec Expo (TypeScript) pour une app mobile appelée "Hēlo" — un scanner de produits pour femmes enceintes, style "Yuka de la grossesse". Le design est Luxe & Serene : tons nude, crème, touches dorées, inspiré des marques skincare haut de gamme. Élégant, apaisant, jamais infantilisant.

SETUP :
- Expo SDK latest avec TypeScript strict
- expo-router pour la navigation file-based
- Structure : app/ (routes), components/ui/ (design system), constants/ (tokens), hooks/, lib/, types/, assets/
- Dépendances : react-native-reanimated, expo-haptics, expo-linear-gradient, @expo-google-fonts/plus-jakarta-sans
