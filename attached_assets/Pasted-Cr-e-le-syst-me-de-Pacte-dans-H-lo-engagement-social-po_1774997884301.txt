Crée le système de Pacte dans Hēlo — engagement social pour scanner quotidiennement.

TABLE SUPABASE pacts :
- id (uuid PK), user_id (uuid FK profiles), start_date (date), duration_days (int default 30), current_streak (int default 0), longest_streak (int default 0), status (text: 'active'/'completed'/'abandoned'), created_at

TABLE pact_witnesses :
- id (uuid PK), pact_id (uuid FK pacts), witness_user_id (uuid FK profiles), invited_via (text: 'circle'/'link')

app/pact.tsx :

CRÉATION DU PACTE :
- "Le Pacte Hēlo" displayMedium doré
- "Engagez-vous à scanner au moins 1 produit par jour pendant 30 jours"
- Illustration : deux mains qui se serrent (style minimaliste doré)
- Choix durée : 7 jours (débutant) / 14 jours / 30 jours (chips)
- "Invitez vos témoins" : sélectionner 1-3 amies du Cercle OU partager un lien d'invitation
- Bouton "Je m'engage" primary → animation signature dorée (comme une signature manuscrite qui se dessine)

SUIVI QUOTIDIEN :
- Widget sur le home : flamme dorée 🔥 + "Jour X/30" + streak counter
- La flamme grandit avec le streak (petite au jour 1, grande au jour 15, énorme au jour 30)
- Animation Reanimated : la flamme pulse doucement

QUAND L'UTILISATRICE SCANNE (quotidien) :
- Notification aux témoins : "[Prénom] a tenu son pacte — jour X/30 ✓ 🔥"
- Animation de célébration sur le home (mini confettis dorés)
- Haptic Success

SI ELLE OUBLIE UN JOUR :
- 20h notification : "Vous n'avez pas encore scanné aujourd'hui — votre pacte vous attend 💛"
- Si minuit passe sans scan : streak reset à 0
- Notification aux témoins : "[Prénom] a besoin d'encouragement 💛" + bouton "Envoyer un mot" → message pré-rédigé

RÉCOMPENSES :
- 7 jours streak : badge "Première semaine 🌱" dans le profil
- 14 jours : badge "Deux semaines 🌿"
- 30 jours : badge "Maman Engagée 🏆" + 1 mois de premium offert (ou réduction)
- Les badges sont affichés dans le profil et partageables

DONNÉES : vérifier si un scan a été fait aujourd'hui via AsyncStorage "last_scan_date". Mettre à jour le streak au premier scan de la journée.
