Crée le système d'alternatives "The Swap" dans l'app Hēlo — quand un produit est caution/danger, proposer des alternatives safe.

AJOUTER AU SCHEMA SUPABASE (ou créer via l'interface Supabase) :
TABLE product_alternatives : id (uuid PK), source_product_id (uuid FK products), alternative_product_id (uuid FK products), category (text), price_range (text: 'budget'/'mid'/'premium'), popularity_count (int default 0), created_at (timestamptz)

ÉCRAN ALTERNATIVES (app/alternatives.tsx, reçoit productId + category en params, affiché comme modal) :

HEADER :
- "Alternatives compatibles" headlineLarge
- "Vérifiées pour votre Xème trimestre" bodyMedium textSecondary
- Card du produit original en petit : image + nom + badge caution/danger avec une barre oblique (style "barré")

SI DES ALTERNATIVES EXISTENT :
ScrollView horizontal (pagingEnabled, snapToInterval) de cartes :
Chaque carte (width screenWidth - 64, marginHorizontal 8) :
- Card elevated, radius xl, padding 0 (image full width en haut)
- Image produit (height 200, radius top xl, fond surfaceElevated si pas d'image)
- Padding 20 pour le contenu :
  * Nom en headlineMedium
  * Marque en bodyMedium textSecondary
  * Badge "Compatible ✓" safe
  * Badge prix : "€" (budget) / "€€" (mid) / "€€€" (premium) en bodySmall
  * "Choisi par X mamans" bodySmall textSecondary avec icône cœur accent
  * Divider
  * Bouton "Voir le détail" ghost → navigue vers verdict de ce produit
  * Bouton "Ajouter à ma liste" secondary

DOTS : indicateur de position (nombre de cartes)

- "Nous recherchons des alternatives pour ce type de produit." bodyMedium textSecondary

- Bouton "Suggérer une alternative" ghost → ouvre un simple formulaire (nom produit + marque + catégorie → insert community_submissions)

lib/alternatives.ts : getAlternatives(productId, category, trimester) — query Supabase product_alternatives JOIN products WHERE verdict=safe pour le trimestre, ORDER BY popularity_count DESC, LIMIT 5.
