Crée l'écran "Mon Placard" de l'app Hēlo — la bibliothèque personnelle de produits scannés.

ÉCRAN app/(tabs)/shelf.tsx :

HEADER :
- "Mon Placard" displayMedium
- Row sous le titre : "X produits" bodyMedium textSecondary + "·" + "Y% compatibles" bodyMedium safe
- IconButton filtre en haut à droite

FILTRES (bottom sheet modal au tap filtre) :
- "Filtrer" headlineMedium
- Section "Verdict" : 4 chips (Tous / Compatibles / Précaution / À éviter), multi-select, style : fond accentLight + texte accent quand sélectionné
- Section "Catégorie" : 3 chips (Salle de bain / Cuisine / Pharmacie)
- Section "Trier par" : 2 options (Plus récents / Plus anciens)
- Bouton "Appliquer" primary + "Réinitialiser" ghost

GRILLE (FlatList numColumns={2}, gap 12, padding horizontal 16) :
Chaque carte produit (Card component) :
- Image (ratio 1:1, radius lg en haut, fond surfaceElevated + icône catégorie centrée si pas d'image)
- Padding 12 :
  * Nom bodyMedium, numberOfLines 2
  * Marque bodySmall textSecondary
- Footer row : Badge verdict (petit, bas gauche) + icône catégorie (bas droite, 16px, textTertiary)
- Si le verdict a changé au changement de trimestre : point doré (8px, position absolute top right 8, fond accent, radius full)
- Tap → navigation vers verdict screen
- Long press → ActionSheet : "Supprimer du placard" / "Changer de catégorie" / "Annuler"

ÉTAT VIDE (quand 0 produits) :
- Centré verticalement
- Illustration SVG (placard ouvert avec étoiles dorées)
- "Votre placard est vide" headlineMedium, marginTop 24
- "Scannez votre premier produit pour construire votre placard safe" bodyMedium textSecondary, textAlign center, marginTop 8
- Bouton "Scanner un produit" primary, marginTop 24 → navigue vers tab scan

TAB "MA LISTE" (SegmentedControl ou toggle en haut : "Mon placard" | "Ma liste") :
- La liste contient les produits marqués "à acheter" (alternatives choisies dans The Swap)
- Même layout en liste (pas grille) avec checkbox à gauche
- Checkbox cochée = opacity 0.5 + strikethrough sur le nom
- Swipe left → bouton "Retirer" rouge rosé

Query Supabase : scans WHERE user_id = current AND in_shelf = true, JOIN products. Skeleton loading (shimmer doré) pendant le chargement.
